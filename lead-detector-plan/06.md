# 06 — Adaptador de fuente: Hacker News

## Contexto
**Lead Detector** monitorea plataformas online buscando gente que busca contratar un developer, filtra los posts con IA (Claude) y avisa por WhatsApp. Stack: Next.js (App Router) + Supabase + Claude API + Wassenger.

Paso **06 de 35**.

**Ya existe:** `lib/sources/types.ts` (`RawItem`, `SourceAdapter`, `FetchResult`), `lib/sources/registry.ts`, `lib/sources/index.ts` (04); `lib/http.ts` (`fetchWithRetry`) y `lib/logger.ts` (02); fila en `sources` con slug `hackernews` (03).

Este paso implementa el **primer adaptador de fuente**: Hacker News. API pública, gratis, sin autenticación.

## API a usar (Algolia HN Search — gratis, sin auth)
- Comentarios recientes: `https://hn.algolia.com/api/v1/search_by_date?tags=comment&query=<QUERY>&numericFilters=created_at_i><UNIX_TS>`
- Encontrar el hilo mensual de freelancers: `https://hn.algolia.com/api/v1/search?query=Ask HN Freelancer Seeking freelancer&tags=story&hitsPerPage=5` → elegir el story más reciente cuyo título contenga "Freelancer".
- Comentarios de un hilo: `https://hn.algolia.com/api/v1/search?tags=comment,story_<STORY_ID>&hitsPerPage=1000`

## Tarea
1. **`lib/sources/hackernews.ts`** — implementar `SourceAdapter` con `slug = 'hackernews'`:
   - `configSchema`: Zod → `{ keywordQueries: string[], includeWhoIsHiring: boolean }`.
   - `fetchItems(config, cursor)`:
     - El `cursor` guarda `{ lastCreatedAt: number }` (máximo `created_at_i` ya visto). Si está vacío, usar como piso las últimas ~26 h.
     - Por cada query, llamar `search_by_date` sobre `comment` filtrando `created_at_i > lastCreatedAt`.
     - Si `includeWhoIsHiring` es true, encontrar el hilo mensual de freelancers, traer sus comentarios y quedarse con los que (normalizados) empiezan con `seeking freelancer`.
     - Deduplicar por `objectID`. Devolver `{ items, cursor }` con el cursor actualizado al mayor `created_at_i` visto.
   - Toda llamada HTTP usa `fetchWithRetry` con un `User-Agent` propio. Logueá con `lib/logger.ts`.
2. **Mapeo a `RawItem`**: `externalId` = `objectID`; `title` = primera línea del comentario recortada (o `"HN Freelancer thread"`); `body` = texto del comentario sin HTML; `url` = `https://news.ycombinator.com/item?id=<objectID>`; `author` = `author`; `postedAt` = `created_at`; `raw` = el hit.
3. **Registrar** el adaptador con `registerSource(...)` e importarlo desde `lib/sources/index.ts`.
4. **`scripts/test-hackernews.ts`** — script `npx tsx` que ejecuta el adaptador con el `config` real (cursor vacío) e imprime cuántos items trajo, los primeros 3 y el cursor resultante.

## Decisiones de diseño
- El adaptador **solo trae y normaliza**. No filtra por keywords ni clasifica.
- **Polling incremental**: el cursor evita re-traer lo mismo en cada poll.

## Criterio de éxito
- `npx tsx scripts/test-hackernews.ts` corre sin errores, trae `RawItem`s con `externalId`/`body`/`url` no vacíos y devuelve un cursor con `lastCreatedAt`.
- `getSource('hackernews')` devuelve el adaptador desde el registry.
- `npm run build` pasa.
