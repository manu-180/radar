# 05 — Normalización y pre-filtro de keywords

## Contexto
**Lead Detector** monitorea plataformas online buscando gente que busca contratar un developer, filtra los posts con IA (Claude) y avisa por WhatsApp. Stack: Next.js (App Router) + Supabase + Claude API + Wassenger.

Paso **05 de 35**.

**Ya existe:** `lib/env.ts`, `lib/supabase/admin.ts`, infraestructura compartida (00–02); esquema con la tabla `keywords` (03); `lib/sources/types.ts` con `RawItem` (04).

Este paso construye el **pre-filtro determinístico**: descarta el grueso del ruido por keywords antes de gastar en IA.

## Tarea
1. **`lib/filter/normalize.ts`**:
   - `normalizeText(s: string): string` — minúsculas, sin acentos/diacríticos, espacios colapsados, trim.
   - `contentHash(item: RawItem): string` — `sha256` (módulo `crypto` de Node) sobre `normalizeText(title + ' ' + body + ' ' + url)`.
   - `detectLang(text: string): 'es' | 'en' | 'other'` — usa `franc-min`. En textos muy cortos la detección es ruidosa; ante baja confianza, devolver `'other'`.
2. **`lib/filter/prefilter.ts`** (con `import 'server-only'`):
   - `loadKeywords()` — lee la tabla `keywords` (solo `enabled = true`) con `getAdminClient()`.
   - `prefilter(item: RawItem, lang: string, keywords): { passed: boolean; matched: string[]; reason: string }`:
     - Normaliza `title + ' ' + body` con `normalizeText`.
     - Una keyword "aplica" si su `lang` es `any` o coincide con el `lang` del item.
     - **Excluir** (`passed=false`) si el texto contiene alguna keyword `exclude` aplicable.
     - Si no hubo exclusión, **pasa** (`passed=true`) si contiene al menos una keyword `include` aplicable.
     - Devolver los términos que matchearon y una `reason` legible. Matching por substring sobre texto normalizado.
3. **Tests** en `test/`: `test/normalize.test.ts` (hash estable ante casing/acentos; `detectLang` es/en) y `test/prefilter.test.ts` (include/exclude en es y en).

## Decisiones de diseño
- El pre-filtro es determinístico y gratis; su objetivo es descartar ruido. Preferí **recall sobre precision** — la IA del paso 13 absorbe los falsos positivos.
- Multi-idioma (español e inglés) de punta a punta.

## Criterio de éxito
- `npm test` pasa, incluyendo los tests de `normalize` y `prefilter`.
- `contentHash` devuelve el mismo hash ante cambios de casing o acentos.
- El pre-filtro deja pasar "Necesito un desarrollador web" y rechaza "Busco trabajo como developer".
- `npm run build` pasa.
