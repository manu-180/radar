# 28 — Deploy a Vercel

## Contexto
**Lead Detector** monitorea plataformas online buscando gente que busca contratar un developer, filtra los posts con IA (Claude) y avisa por WhatsApp. Stack: Next.js (App Router) + Supabase + Claude API + Wassenger + Vercel.

Paso **28 de 35**.

**Ya existe:** la aplicación completa con las fuentes Hacker News, Reddit, Bluesky, Freelancer.com y RSS — polling, clasificación, notificaciones, dashboard, configuración, métricas, monitoreo de salud y CI (pasos 00–27); `supabase/cron.sql` con los 4 jobs de cron (18, 26). MCP de Supabase conectado.

Este paso pone el sistema **en producción**. (Telegram, Discord y Workana se suman después, pasos 30–34.)

## Tarea
1. **Preparar el repo**: si no es un repo Git, inicializarlo (`git init`, commit inicial). Confirmar que `.env.local` está en `.gitignore`.
2. **Crear el proyecto en Vercel y deployar**: si tenés el **MCP de Vercel** conectado, usalo; si no, `npx vercel` (requiere `npx vercel login` — paso manual).
3. **Cargar las variables de entorno en Vercel** (entorno Production):
   - **Requeridas:** `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `ANTHROPIC_API_KEY`, `WASSENGER_API_KEY`, `WASSENGER_WEBHOOK_SECRET`, `OWNER_WHATSAPP`, `CRON_SECRET`, `AUTH_SECRET`, `REDDIT_USER_AGENT`, `DASHBOARD_PASSWORD`, `APP_URL`.
   - **Opcionales (cargar cuando se configuren esas fuentes):** `FREELANCER_OAUTH_TOKEN`, `DISCORD_BOT_TOKEN`, `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_SESSION`, `SCRAPER_API_KEY`.
   - `APP_URL` debe ser la URL de producción definitiva.
4. **Deployar a producción** y confirmar que el build pasa en Vercel.
5. **Re-apuntar el cron a producción**: re-ejecutar `supabase/cron.sql` (vía MCP) con `APP_URL` = URL de producción. El script es idempotente.
6. **Configurar el webhook de Wassenger** apuntándolo a `${APP_URL}/api/webhooks/wassenger` con el secreto `WASSENGER_WEBHOOK_SECRET`.

## Decisiones de diseño
- El scheduling vive en Supabase Cron: después de un deploy con URL nueva hay que re-correr `cron.sql`.
- Freelancer.com y RSS andan de entrada (Freelancer no-opera sin token, sin romper). Telegram y Discord quedan deshabilitadas hasta sus pasos de setup.

## Criterio de éxito
- La app está deployada en Vercel y el build pasó.
- Las variables de entorno requeridas de Production están todas cargadas.
- `select ... from cron.job` muestra los jobs apuntando a la URL de producción.
- El dashboard de producción carga y pide login.
