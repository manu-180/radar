# 32 — Fuente Discord: setup

## Contexto
**Lead Detector** monitorea plataformas online buscando gente que busca contratar un developer, filtra los posts con IA (Claude) y avisa por WhatsApp. Stack: Next.js (App Router) + Supabase + Claude API + Wassenger + Vercel.

Paso **32 de 35**.

**Ya existe:** el sistema completo en producción (pasos 00–29); `lib/env.ts` con `DISCORD_BOT_TOKEN` opcional (01); fila en `sources` con slug `discord`, deshabilitada (03).

Discord es una **fuente core** del plan (hay servidores activos de "hire developers" con canales de proyectos). Requiere un **setup manual único**: crear un bot e invitarlo a los servidores. Este paso prepara ese setup; el paso 33 implementa el adaptador.

## Tarea
1. **Documentar el setup manual en el README** (sección Discord):
   - Crear una aplicación + bot en `https://discord.com/developers/applications`.
   - Copiar el **token del bot** → variable `DISCORD_BOT_TOKEN` (en `.env.local` y Vercel).
   - En la config del bot, **activar el "Message Content Intent"** (intent privilegiado, necesario para leer el contenido de los mensajes).
   - Invitar el bot a cada servidor objetivo con una URL OAuth2 (scope `bot`, permisos `View Channels` + `Read Message History`). El dueño debe ser admin del servidor o pedirle a un admin que lo apruebe.
   - Con el "Modo desarrollador" de Discord activado, copiar el **ID de cada canal** a monitorear (y el ID del servidor).
2. **`scripts/test-discord.ts`** — script `npx tsx` que, con `DISCORD_BOT_TOKEN` seteado, hace una llamada de prueba a la API de Discord (`GET /users/@me`) y confirma que el token es válido y el bot responde.

## Decisiones de diseño
- El adaptador (paso 33) usará la **API REST de Discord por polling**, no una conexión gateway persistente — encaja con el modelo de polling del sistema y no necesita un proceso siempre activo.
- Degradación elegante: sin `DISCORD_BOT_TOKEN`, la fuente devuelve `[]`.

## Criterio de éxito
- El README documenta el setup paso a paso (crear bot, intent, invitar, IDs de canal).
- Con `DISCORD_BOT_TOKEN` válido, `npx tsx scripts/test-discord.ts` confirma que el bot responde.
- `npm run build` pasa.
