# 00 — Inicializar el proyecto Next.js

## Contexto
**Lead Detector** monitorea plataformas online (Hacker News, Reddit, Bluesky, Freelancer.com, feeds RSS, Telegram, Discord) buscando gente que busca contratar un developer web/apps, filtra los posts con IA (Claude) y avisa al dueño por WhatsApp con un mensaje sugerido listo para responder. Stack: Next.js (App Router, TypeScript) + Supabase + Claude API + Wassenger + Vercel, todo en free tier.

Paso **00 de 35**. El plan está dividido en tareas chicas y acotadas: ejecutá esta completa y verificá el criterio de éxito al final.

El directorio del proyecto está **vacío**.

## Tarea
1. Inicializar Next.js en el directorio actual:
   `npx create-next-app@latest . --typescript --tailwind --app --eslint --no-src-dir --import-alias "@/*" --use-npm`
2. Dependencias: `npm install @supabase/supabase-js @anthropic-ai/sdk zod franc-min`
3. Dependencias de desarrollo: `npm install -D vitest tsx`
4. Crear estas carpetas (vacías por ahora): `lib/supabase/`, `lib/sources/`, `lib/filter/`, `lib/ai/`, `lib/notify/`, `lib/db/`, `supabase/migrations/`, `scripts/`, `types/`, `test/`.
5. **Vitest**: crear `vitest.config.ts` (entorno `node`, incluye `test/**/*.test.ts`). Crear `test/smoke.test.ts` con un test trivial para que la suite arranque en verde.
6. **Scripts de npm** en `package.json`: `test` → `vitest run`; `typecheck` → `tsc --noEmit`; `verify` → corre en orden `next lint`, `typecheck`, `test` y `next build`.
7. Reemplazar `app/page.tsx` por una página simple con el texto "Lead Detector" y "Setup en progreso".
8. Crear `README.md` con el nombre del proyecto y el stack.

## Decisiones de diseño
- TypeScript estricto. Sin carpeta `src/`: rutas en `app/`, lógica en `lib/`, tests en `test/`.
- No instalar `@supabase/ssr`: el dashboard se protege con un password simple (paso 19), no con Supabase Auth.
- `tsx` corre los scripts sueltos (`scripts/*.ts`); `vitest` corre los tests unitarios.

## Criterio de éxito
- `npm run dev` levanta y `http://localhost:3000` muestra la página placeholder.
- `npm run build` pasa sin errores.
- `npm test` corre y el test smoke pasa.
- Existen las 10 carpetas listadas en el punto 4.
