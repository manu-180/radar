# 16 — Cliente de Wassenger y constructor de mensajes

## Contexto
**Lead Detector** monitorea plataformas online buscando gente que busca contratar un developer, filtra los posts con IA (Claude) y avisa por WhatsApp. Stack: Next.js (App Router) + Supabase + Claude API + Wassenger.

Paso **16 de 35**.

**Ya existe:** `lib/env.ts` con `WASSENGER_API_KEY`, `OWNER_WHATSAPP`, `APP_URL` (01); `lib/http.ts` (`fetchWithRetry`) y `lib/logger.ts` (02).

Este paso construye los **módulos de notificación**: el cliente de Wassenger y el armador del mensaje de WhatsApp. (La ruta que los usa es el paso 17.)

## API de Wassenger (verificada)
- Endpoint: `POST https://api.wassenger.com/v1/messages`
- Headers: `Content-Type: application/json` y `Token: <WASSENGER_API_KEY>` (el header se llama literalmente `Token`).
- Body para chat directo: `{ "phone": "+5491112345678", "message": "...", "priority": "high" }`
- Formato WhatsApp: `*negrita*`, `_cursiva_`, `~tachado~`, ` ```monoespaciado``` `. Las URLs sueltas se vuelven clickeables. Saltos de línea con `\n`.

## Tarea
1. **`lib/notify/wassenger.ts`** (con `import 'server-only'`):
   - `sendWhatsApp(phone, message): Promise<{ id: string }>` — `POST` con `fetchWithRetry`, header `Token`. Devuelve el id del mensaje. `fetchWithRetry` maneja `429` y reintentos. Ante un no-2xx no recuperable, lanzar error descriptivo. Logueá con `lib/logger.ts`.
2. **`lib/notify/message.ts`**:
   - `buildLeadMessage(lead): string` — arma el aviso con formato WhatsApp:
     - Título en negrita, ej. `*🎯 Nuevo lead — Reddit*` (con la fuente real del lead).
     - Categoría y score.
     - Un extracto del post (título + primeras líneas del body, recortado a ~280 caracteres).
     - El link al post original.
     - El mensaje sugerido, precedido de `_Respuesta sugerida:_`.
     - Un link al detalle del lead: `${env.APP_URL}/leads/${lead.id}`.

## Decisiones de diseño
- El cliente y el armador son módulos puros y reutilizables: los usan la ruta de notificación (17) y el monitoreo de salud (paso 26).

## Criterio de éxito
- `npm run build` pasa.
- `sendWhatsApp` y `buildLeadMessage` están tipados y exportados.
- `buildLeadMessage` sobre un lead de ejemplo produce un texto con título en negrita, contexto, link y respuesta sugerida.
