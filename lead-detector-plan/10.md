# 10 — Adaptador de fuente: feeds RSS genérico

## Contexto
**Lead Detector** monitorea plataformas online buscando gente que busca contratar un developer, filtra los posts con IA (Claude) y avisa por WhatsApp. Stack: Next.js (App Router) + Supabase + Claude API + Wassenger.

Paso **10 de 35**.

**Ya existe:** `lib/sources/` con la interfaz, el registry y adaptadores de referencia (04, 06–09); `lib/http.ts` y `lib/logger.ts` (02); fila en `sources` con slug `rss` (03).

Este paso implementa un **adaptador RSS genérico**: un único adaptador que lee cualquier cantidad de feeds configurables. Así se suman fuentes nuevas (Craigslist, We Work Remotely, Remotive, Jobicy, y cualquier feed futuro) **solo agregando una entrada en el `config`, sin escribir código**.

## Tarea
1. **Dependencia**: `npm install rss-parser`.
2. **`lib/sources/rss.ts`** — implementar `SourceAdapter` con `slug = 'rss'`:
   - `configSchema`: Zod → `{ feeds: { name: string, url: string }[] }`.
   - `fetchItems(config, cursor)`:
     - El `cursor` guarda `{ [feedName]: lastItemDate }` (ISO del item más nuevo visto por feed).
     - Por cada feed: bajar la URL con `fetchWithRetry`, parsear con `rss-parser`, quedarse con los items posteriores a su `lastItemDate`.
     - Si un feed falla, logueá y seguí con los demás (no abortar todo).
     - Devolver `{ items, cursor }` con el cursor actualizado por feed.
3. **Mapeo a `RawItem`**: `externalId` = `<feedName>:<guid o link>`; `title` = título del item; `body` = `contentSnippet`/`content`; `url` = `link`; `author` = el `feedName` (así se sabe de qué feed vino); `postedAt` = `isoDate`/`pubDate`; `raw` = el item.
4. **Verificar y completar los feeds semilla**: la fila `rss` en `sources` trae feeds de ejemplo. Confirmá que cada URL responde un feed válido y ajustá/sumá feeds útiles (Craigslist `computer gigs` de ciudades grandes con `?format=rss`, We Work Remotely categorías de programación, Remotive, Jobicy). Actualizá el `config` de la fila `rss` vía el MCP de Supabase.
5. **Registrar** el adaptador con `registerSource(...)` e importarlo desde `lib/sources/index.ts`.
6. **`scripts/test-rss.ts`** — script `npx tsx` que ejecuta el adaptador con el `config` real e imprime cuántos items trajo por feed y los primeros 3.

## Decisiones de diseño (respetalas)
- **Un adaptador, N fuentes**: este es el punto clave de escalabilidad — sumar un feed RSS nuevo es una fila de `config`, no código. Ideal para cubrir muchas plataformas con esfuerzo mínimo.
- El `feedName` viaja en `author` para no perder de qué feed salió cada lead.
- Las bolsas de empleo remoto (WWR, Jobicy) traen más empleo full-time que changas freelance: son un extra gratis, no la fuente principal. Craigslist `computer gigs` sí tiene pedidos reales de proyectos.

## Criterio de éxito
- `npx tsx scripts/test-rss.ts` corre sin errores y trae `RawItem`s de al menos un feed, con `externalId`/`title`/`url` no vacíos y un cursor por feed.
- Si un feed individual falla, el adaptador igual devuelve los items de los demás.
- `getSource('rss')` devuelve el adaptador desde el registry.
- `npm run build` pasa.
