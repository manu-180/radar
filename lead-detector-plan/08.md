# 08 — Adaptador de fuente: Bluesky

## Contexto
**Lead Detector** monitorea plataformas online buscando gente que busca contratar un developer, filtra los posts con IA (Claude) y avisa por WhatsApp. Stack: Next.js (App Router) + Supabase + Claude API + Wassenger.

Paso **08 de 35**.

**Ya existe:** `lib/sources/` con la interfaz, el registry y los adaptadores `hackernews`/`reddit` como referencia (04, 06, 07); `lib/http.ts` (`fetchWithRetry`) y `lib/logger.ts` (02); fila en `sources` con slug `bluesky` (03).

Este paso implementa el **adaptador de Bluesky**. Es la fuente social de mejor relación valor/esfuerzo: API pública, **gratis y sin autenticación**.

## API a usar (Bluesky / AT Protocol — gratis, sin auth)
- Búsqueda de posts: `GET https://public.api.bsky.app/xrpc/app.bsky.feed.searchPosts?q=<QUERY>&sort=latest&limit=100&cursor=<CURSOR>`
- No requiere login ni token para búsqueda de solo lectura. Rate limit holgado para lecturas.
- Los parámetros `since`/`until` son poco confiables — **no los uses**; ordená por `latest` y deduplicá por la `uri` del post.

## Tarea
1. **`lib/sources/bluesky.ts`** — implementar `SourceAdapter` con `slug = 'bluesky'`:
   - `configSchema`: Zod → `{ queries: string[] }`.
   - `fetchItems(config, cursor)`:
     - El `cursor` guarda `{ lastIndexedAt: string }` (ISO del post más nuevo ya visto).
     - Por cada query, llamar `searchPosts` con `sort=latest`, paginando con el `cursor` de la API **hasta** llegar a posts con `indexedAt <= lastIndexedAt` (o agotar unas pocas páginas).
     - Devolver `{ items, cursor }` con el cursor actualizado al `indexedAt` más nuevo visto.
   - Toda llamada usa `fetchWithRetry`. Logueá con `lib/logger.ts`.
2. **Mapeo a `RawItem`**: `externalId` = la `uri` del post (`at://...`); `title` = primera línea del texto recortada; `body` = `record.text`; `url` = `https://bsky.app/profile/<author.handle>/post/<rkey>` (el `rkey` es el último segmento de la `uri`); `author` = `author.handle`; `postedAt` = `indexedAt`; `raw` = el post.
3. **Registrar** el adaptador con `registerSource(...)` e importarlo desde `lib/sources/index.ts`.
4. **`scripts/test-bluesky.ts`** — script `npx tsx` que ejecuta el adaptador con el `config` real (cursor vacío) e imprime cuántos items trajo, los primeros 3 y el cursor.

## Decisiones de diseño
- El adaptador **solo trae y normaliza**, igual que HN y Reddit — la misma interfaz, cero impacto en el resto del sistema.
- Sin credenciales: nada que configurar, la fuente arranca habilitada.

## Criterio de éxito
- `npx tsx scripts/test-bluesky.ts` corre sin errores, trae `RawItem`s con `externalId`/`body`/`url` no vacíos y devuelve un cursor con `lastIndexedAt`.
- `getSource('bluesky')` devuelve el adaptador desde el registry.
- `npm run build` pasa.
