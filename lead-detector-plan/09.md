# 09 — Adaptador de fuente: Freelancer.com

## Contexto
**Lead Detector** monitorea plataformas online buscando gente que busca contratar un developer, filtra los posts con IA (Claude) y avisa por WhatsApp. Stack: Next.js (App Router) + Supabase + Claude API + Wassenger.

Paso **09 de 35**.

**Ya existe:** `lib/sources/` con la interfaz, el registry y adaptadores de referencia (04, 06–08); `lib/http.ts` y `lib/logger.ts` (02); `FREELANCER_OAUTH_TOKEN` (opcional) en `lib/env.ts` (01); fila en `sources` con slug `freelancer` (03).

Este paso implementa el **adaptador de Freelancer.com**, una bolsa donde **cada resultado es un proyecto donde alguien explícitamente quiere contratar**.

## API a usar (API oficial de Freelancer.com — gratis)
- Proyectos activos: `GET https://www.freelancer.com/api/projects/0.1/projects/active?query=<QUERY>&...`
- Auth: header `freelancer-oauth-v1: <FREELANCER_OAUTH_TOKEN>`. El token sale de la cuenta del dueño (un token personal alcanza para búsqueda de solo lectura).
- Pedir los detalles del proyecto (`&full_description=true&job_details=true` o equivalente) para tener título y descripción.

## Tarea
1. **`lib/sources/freelancer.ts`** — implementar `SourceAdapter` con `slug = 'freelancer'`:
   - `configSchema`: Zod → `{ queries: string[] }`.
   - `fetchItems(config, cursor)`:
     - **Si `FREELANCER_OAUTH_TOKEN` no está seteado, devolver `{ items: [], cursor }` sin error** (la fuente queda inerte hasta configurarse).
     - El `cursor` guarda `{ lastSubmitDate: number }` (unix).
     - Por cada query, llamar al endpoint de proyectos activos; quedarse con los proyectos con `submitdate > lastSubmitDate`.
     - Devolver `{ items, cursor }` con el cursor al mayor `submitdate` visto.
   - Toda llamada usa `fetchWithRetry`. Logueá con `lib/logger.ts`.
2. **Mapeo a `RawItem`**: `externalId` = el id del proyecto; `title` = título del proyecto; `body` = descripción; `url` = `https://www.freelancer.com/projects/<seo_url>` (o la URL por id); `author` = el employer si está disponible; `postedAt` = `submitdate` → ISO; `raw` = el proyecto.
3. **Registrar** el adaptador con `registerSource(...)` e importarlo desde `lib/sources/index.ts`.
4. **`scripts/test-freelancer.ts`** — script `npx tsx` que ejecuta el adaptador e imprime los items (o, sin token, confirma que devuelve `[]` sin error).
5. **Documentar** en el README cómo obtener `FREELANCER_OAUTH_TOKEN` (cuenta de Freelancer.com → developers/API → token).

## Decisiones de diseño
- **Degradación elegante**: sin token, la fuente devuelve `[]` y el resto del sistema sigue intacto. Obtener el token es un trámite menor, no un bloqueante.

## Criterio de éxito
- Con `FREELANCER_OAUTH_TOKEN` válido, `npx tsx scripts/test-freelancer.ts` trae proyectos como `RawItem`s con `externalId`/`title`/`url` no vacíos.
- Sin token, el adaptador devuelve `[]` sin lanzar error.
- `getSource('freelancer')` devuelve el adaptador desde el registry.
- `npm run build` pasa.
