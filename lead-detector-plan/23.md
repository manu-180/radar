# 23 — Panel de configuración: fuentes y ajustes generales

## Contexto
**Lead Detector** monitorea plataformas online buscando gente que busca contratar un developer, filtra los posts con IA (Claude) y avisa por WhatsApp. Stack: Next.js (App Router) + Supabase + Claude API + Wassenger.

Paso **23 de 35**.

**Ya existe:** la página `app/(dashboard)/config/page.tsx` con la sección de keywords (22); esquema con `sources` y `settings` (03); el registry de fuentes, donde cada adaptador expone su `configSchema` de Zod (04).

Este paso completa el panel de configuración con **fuentes** y **ajustes generales**.

## Tarea
Ampliar `app/(dashboard)/config/page.tsx` con dos secciones nuevas:
1. **Fuentes**:
   - Listar las `sources` (las 7+: hackernews, reddit, bluesky, freelancer, rss, telegram, discord) con su estado `enabled` y su `config`.
   - Server actions para activar/desactivar una fuente y editar su `config` (editor de texto JSON).
   - **Validar el `config` contra el `configSchema` de Zod del adaptador correspondiente** (vía el registry) antes de guardar; si es inválido, mostrar el error y no guardar.
   - Para la fuente `rss`, el `config` incluye la lista de feeds — desde acá se agregan/quitan feeds sin tocar código.
2. **Ajustes generales** (tabla `settings`):
   - Editar `notify_rule` (categorías y `minScore`). Validar el JSON.
   - Editar `max_notifications_per_run`.
   - Editar `freelancer_profile` (la bio que usa la IA para personalizar las respuestas).

## Decisiones de diseño
- Todo el comportamiento del sistema se ajusta desde la web, sin tocar código ni redeployar.
- La validación contra el `configSchema` real del adaptador evita que un valor inválido rompa el polling.

## Criterio de éxito
- En `/config` se puede activar/desactivar una fuente y editar su `config`; un `config` que no pasa el `configSchema` se rechaza con un mensaje claro.
- Se pueden agregar/quitar feeds RSS editando el `config` de la fuente `rss`.
- Editar `notify_rule`, `max_notifications_per_run` y `freelancer_profile` persiste en `settings`.
- `npm run build` pasa.
